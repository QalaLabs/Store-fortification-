## Quick Start (Local Development)

Zero external AWS credentials or database infrastructure required for offline local evaluation.

```bash
# Install dependencies
pnpm install

# Run TypeScript typecheck
pnpm run typecheck

# Run test suite
pnpm test

# Run ESLint
pnpm run lint

# Run Next.js production build
pnpm run build

# Start local server
pnpm run dev
```
